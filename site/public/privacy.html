Privacy

This site sets no cookies, runs no analytics and loads nothing from anyone else: the fonts and images come from this site.

Downloads

The download buttons send you to the file on GitHub Releases. GitHub counts how many times each file is downloaded, and that count is the only number we look at. It is public, and you can see it on the download stats page. We do not keep your IP address, browser or anything else about you.

The app

Matty talks to the Mattermost servers you sign in to, and to GitHub to check for updates. It has no telemetry. Your sign-in tokens stay on your computer, in the system keychain on macOS.

Hosting

The site runs on Cloudflare, which handles requests on our behalf under its own privacy policy.
