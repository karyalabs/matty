Privacy

This site sets no cookies, runs no analytics and loads nothing from anyone else: the fonts and images come from this site. The one thing it counts is downloads.

Downloads

The download buttons send you to the file on GitHub Releases. On the way, the site adds one to a counter for that day, file and Matty version, and notes whether the request looked automated (a link preview or a crawler), judged from the browser's name without keeping it. That is all it keeps: no IP address, no browser details, no referrer, nothing that tells one visitor from another. The counts are public on the download stats page.

GitHub keeps its own count of how many times each release file is downloaded, which is public too.

The app

Matty talks to the Mattermost servers you sign in to, and to GitHub to check for updates. It has no telemetry. Your sign-in tokens stay on your computer, in the system keychain on macOS.

Hosting

The site runs on Cloudflare, which handles requests on our behalf under its own privacy policy.
