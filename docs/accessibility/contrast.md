# Contrast

Every foreground/background pair Matty draws, with its WCAG 2.1 contrast ratio. Text needs 4.5:1 and other UI (focus rings, presence dots, badges) needs 3:1. Translucent fills are composited over the surface they sit on.

This file is generated by `crates/matty-app/src/contrast.rs`. To refresh it, run
`MATTY_WRITE_CONTRAST=1 cargo test -p matty-app contrast`.
