# Contrast

Every foreground/background pair Matty draws, with its WCAG 2.1 contrast ratio. Text needs 4.5:1 and other UI (focus rings, presence dots, badges) needs 3:1. Translucent fills are composited over the surface they sit on. The name of a channel you muted is dimmed on purpose and held to 3:1.

The tables are for the default theme. Every built-in theme, in light and dark and at both contrast levels, is held to the same minimums by the tests in `crates/matty-app/src/style/palette.rs`, and Settings shows the result for a theme you make.

This file is generated by `crates/matty-app/src/contrast.rs`. To refresh it, run
`MATTY_WRITE_CONTRAST=1 cargo test -p matty-app contrast`.
